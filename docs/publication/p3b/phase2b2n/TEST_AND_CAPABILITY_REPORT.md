# Test and Capability Report

Focused test command: `python -m pytest -q tests/test_publication_m53_network_guard.py`.

Result after independent adversarial review: **81 collected — 80 passed, 1 skipped** on Windows CPython 3.12 (`os.fork` is POSIX-only; on Linux the `os.startfile` case skips instead). Tests use only pytest temporary directories and temporary local Git repositories.

**No test opens a socket of any kind.** No test resolves a real DNS name, connects to a real host, opens a loopback socket, or sends a packet. Socket denial is demonstrated two ways: non-resolvable `.invalid` values are intercepted before any operating-system networking operation, and the guard's replaced callables are invoked directly against inert in-process stub objects, so there is no socket to connect with even in principle. Audit-layer denial is exercised by calling the hook with synthetic event tuples.

- **Bootstrap/import integrity** — both guard files hashed and pinned; a mismatched `sitecustomize` digest fails closed; a `guard_core`/`sitecustomize` pair on an earlier `PYTHONPATH` entry fails closed; a shadow pair inside the historical checkout and in the current working directory never runs; a guard directory inside the checkout fails closed; the guard directory must be first on `PYTHONPATH`; direct import of `guard_core` cannot self-activate; every evidence record carries both file digests.
- **Environment clearing** — the cleared set is asserted against the full Phase 2B-2A credential/proxy list plus uppercase and lowercase `HTTP_PROXY`, `HTTPS_PROXY`, `ALL_PROXY`, `NO_PROXY`, `FTP_PROXY` and the Alpaca/APCA endpoint aliases; sentinel values for all sixteen Phase 2B-2A names are proven absent from the target's `os.environ` and from the evidence log; the allowed Git child's environment is proven to contain nothing beyond the four controlled keys; reintroducing a cleared or configuration variable is denied.
- **Executable provenance** — activation evidence is proven to hash Python and Git **file bytes**, distinct from the path-string digest; an absent or mismatched `ORB_M53_GUARD_GIT_SHA256` or `ORB_M53_GUARD_PYTHON_SHA256` fails closed before target import; an approved Git child records the pinned content hash.
- **Network denial** — internet socket construction denied at `socket.__new__`; `connect`, `connect_ex`, `send`, `sendall`, `sendto`, `bind`, `getaddrinfo`, `gethostbyname`, `gethostbyname_ex`, `getnameinfo`, `create_connection`, `socketpair` each denied by name; `urllib` HTTP denied; inherited-descriptor rewrapping denied; an unknown future `socket.*` audit event denied by prefix.
- **Descendant denial** — arbitrary, shell, child-Python, PowerShell, cmd, curl, keyword-form `Popen`, `os.system`, and `multiprocessing` denials; the `os.exec*` family, `os.spawnv`, `os.startfile`, and `os.fork` denials; the two exact Git vectors allowed and counted; near-match, case-variant, trailing-argument, `-c` override, alias, hook, `fetch`, `ls-remote`, and string-form Git denials; wrong and unspecified `cwd`; substituted `executable`; `preexec_fn`/`pass_fds`/`startupinfo` denial on an otherwise-approved vector; a saved pre-patch `Popen` reference still denied by the audit hook.
- **Evidence** — activation is distinguishable from readiness by its `false` rule-loaded booleans; secret, raw-cache, and username redaction; tamper detection; truncation rejection; missing terminal record, missing `guard_ready`, present `denied_*`, and absent file each rejected by `verify_guard_run()`; a deliberately rewritten chain shown to re-verify structurally, demonstrating the documented authenticity limit.
- **Determinism and isolation** — the guard source imports no project module, and two runs are structurally identical except timestamp, PID, working-directory, and hash-chain fields.
