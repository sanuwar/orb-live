# Data License and Redistribution Matrix

**This is not legal advice.** It is a documentation review of publicly stated policies for the exact data sources M43–M55 actually used, to be confirmed by a knowledgeable human/legal reviewer before any public release or redistribution decision (per `PUBLICATION_GAP_PLAN.md`'s data-license-review work package). No source below was logged into, no market data was downloaded, and no authenticated endpoint was tested while producing this matrix — every row is based on reading public policy pages plus what M43–M55's own committed reports already document about how each source was used.

## Data-availability limitation discovered by the record itself (not a licensing issue)

Independent of licensing, `docs/research/ORB_UNTOUCHED_2019_2020_VALIDATION_FEASIBILITY.md` establishes that Alpaca's IEX minute-bar feed has a hard coverage floor: **zero minute bars exist for any session before 2020-07-27**, confirmed by bisection across four symbols and dozens of individual dates. Daily SIP coverage does not share this floor (confirmed complete for 19/20 tested ETF symbols across 2018–2020, with the 20th excluded only for a genuine pre-launch date). This is a technical coverage gap, not a licensing restriction, and is recorded here because it bears directly on which historical validation windows are reproducible at all, regardless of licensing.

## What this matrix does not authorize

This matrix does not itself license, publish, upload, or redistribute any data. No account was created or logged into, no market-data endpoint was called, and no bulk download was attempted while producing it. The Alpaca row's unresolved status is, on its own, sufficient to block any "public raw market data" claim in `REPRODUCIBILITY_AND_ARCHIVE_BLUEPRINT.md` until a human reads the two linked underlying agreements.
