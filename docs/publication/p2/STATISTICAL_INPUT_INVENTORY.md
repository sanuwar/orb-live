## Classification legend

- **AVAILABLE_COMMITTED** — the exact granular series/observations exist in a committed file, citeable by path/commit/blob hash.
- **DERIVABLE_OFFLINE** — not committed at the required granularity, but reproducible without new network access from a locally cached, already-fetched vendor response (gitignored `artifacts/research-*/results/` caches) plus committed, deterministic research code.
- **SUMMARY_ONLY** — only aggregate/scalar figures are committed (means, drawdowns, classifications); the underlying trade- or session-level series is not committed and, for at least one milestone, no longer exists as a stable local cache either.
- **NOT_AVAILABLE** — the input does not exist in any form accessible to this repository today.
- **LICENSE_RESTRICTED** — technically obtainable, but redistribution/publication rights are not established (see `DATA_LICENSE_REDISTRIBUTION_MATRIX.md`).
- **PROSPECTIVE_PENDING** — the input is defined by the M55 protocol but does not exist yet because no monthly cycle has completed.
