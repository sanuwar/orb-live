## Classification legend (committed-evidence basis only)

- **AVAILABLE_COMMITTED** — the exact granular series/observations exist in a committed file, citeable by path/commit/blob hash.
- **SUMMARY_ONLY** — only aggregate/scalar figures are committed (means, drawdowns, classifications); the underlying trade- or session-level series is not committed to Git. This is now used for every row where P2 has not itself verified a granular series exists and is intact, including rows where a local cache *might* still hold it.
- **NOT_AVAILABLE** — the input does not exist in any form accessible to this repository today, committed or cached.
- **LICENSE_RESTRICTED** — technically obtainable, but redistribution/publication rights are not established (see `DATA_LICENSE_REDISTRIBUTION_MATRIX.md`).
- **PROSPECTIVE_PENDING** — the input is defined by the M55 protocol but does not exist yet because no monthly cycle has completed.

`DERIVABLE_OFFLINE` is retired as a classification value in this document. It asserted availability P2 never verified. Where a cache-dependent regeneration path is plausible, it is now stated separately, in its own column, as an explicitly unverified candidate — never as a classification.

## Required P3 cache-integrity preflight (not run in P2)

Before any P3 execution treats a `SUMMARY_ONLY`-classified, cache-dependent row above as usable granular evidence, it must run and pass a preflight that, at minimum: (1) confirms the relevant `artifacts/research-*/results/` cache directory exists on the machine running P3; (2) confirms its contents are unmodified since the milestone's own commit (e.g., by checking recorded fetch parameters/timestamps against the milestone's hash manifest where one exists); (3) confirms regenerating from that cache reproduces the exact `study_results_json_sha256` (or equivalent) already pinned in the milestone's committed hash manifest; and (4) documents the preflight's own pass/fail result as a new, separately committed artifact before any bootstrap, regression, or hypothesis test consumes the resulting series. Skipping this preflight and directly opening a cache "because it's probably fine" is exactly the unverified-assumption this correction pass removes.

No granular observation in this inventory was estimated, interpolated, or reconstructed from a summary statistic.
